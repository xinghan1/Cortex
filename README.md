# Synora code · Windows 多模型编程助手

Synora code 是本地运行的 AI 编程桌面基础版。支持 OpenAI GPT、DeepSeek 和 Anthropic Claude 的官方 API，也提供独立“中转站”选项，支持 Chat Completions 与 Responses 两种接口协议。

开发者：[兴汉1](https://github.com/xinghan1)。AI 编程协作：ChatGPT。

## 下载与安装

打开 [GitHub Releases 下载页](https://github.com/xinghan1/Synora-code/releases/latest)，在 Assets 中选择 Windows x64 版本：

| 版本 | 下载文件 | 使用方式 | 本机数据位置 |
| --- | --- | --- | --- |
| 安装版 | `Synora-code-Setup-0.21.2-x64.exe` | 双击 EXE，按安装向导选择目录；安装后从快捷方式启动 | `%APPDATA%\Synora code\` |
| 便携版 | `Synora-code-0.21.2-win32-x64.zip` | 完整解压后双击文件夹内的 `Synora code.exe` | EXE 同级的 `data\` |

两种版本均无需安装 Node.js。安装版按当前 Windows 用户安装，更新后继续使用固定数据目录，卸载默认保留本机数据；便携版需保留整个解压目录，移动时一并保留 `data\`。安装版与便携版使用各自的数据目录。

发布包未做代码签名，Windows 可能显示发布者未知；下载时请核对仓库和版本。发布包不包含个人配置、账号凭据或 API Key。

## 从源码编译

需要 **Windows x64、Node.js 22.12 或更新版本及 npm**。在 PowerShell 中执行：

```powershell
git clone https://github.com/xinghan1/Synora-code.git
cd Synora-code
npm.cmd ci
npm.cmd run prepare:sdk
npm.cmd test
npm.cmd run build
npm.cmd run build:installer
```

`npm run build` 生成便携版 `dist/Synora-code-0.21.2-win32-x64/`，双击其中的 `Synora code.exe` 即可运行，分发时需保留整个文件夹。构建脚本会拒绝覆盖同名便携目录；重新构建时，请先把已有输出目录改名留存。

`npm run build:installer` 生成安装版 `installer-output/Synora-code-Setup-0.21.2-x64.exe`，可双击进入安装向导。它从源码独立打包，不依赖上一步的便携版目录；只需要安装版时可跳过 `npm run build`。构建不会自动发布 GitHub Release 或运行生成的程序。

`npm ci` 按锁文件安装依赖，首次运行或构建会下载 Electron 运行时，因此需要联网，且不能省略开发依赖。`prepare:sdk` 从仓库内的 TypeScript 源码生成 ChatGPT 登录组件，无需另外克隆第三方仓库。运行开发界面使用 `npm.cmd start`。

仓库仅包含程序源码、测试、资源和构建配置，不包含个人会话、账号凭据、API Key、依赖目录或已编译的 EXE。GitHub Actions 会在 Windows 上测试并构建便携版和安装版，在成功的运行页面分别提供两类 artifact，保留 14 天；工作流只上传构建产物，不自动创建或发布 Release。

ChatGPT 登录组件及其修改遵循随附的**非商业许可**，详见 [第三方组件说明](THIRD_PARTY_NOTICES.md)。

## 检查更新

Windows x64 安装版每次启动约 5 秒后检查本仓库的 GitHub Releases，之后每 4 小时检查一次；也可通过 **帮助 → 检查更新** 手动检查。仅接受正式发布的更高版本，不把草稿、预发布或普通 Git 提交作为更新。没有新版本或自动检查网络失败时，顶部不增加按钮。

发现新版后，顶部“帮助”右侧显示带下载箭头的圆形图标，背景跟随“颜色风格”。点击后在窗口中央显示下载弹窗，实时显示进度条、百分比和“已下载 / 总大小”，按大小自动使用 KB、MB、GB。关闭弹窗可在后台继续下载，再点顶部图标可重新查看；下载失败可在弹窗重试。完成校验后，可点击“重启更新”退出程序、更新原安装并重新启动。下载期间可以继续使用软件；安装前需要结束所有窗口的模型或终端任务、保存文件，并发送或移除待发送消息。本机配置和会话仍使用原应用数据目录。下载或安装启动失败会提示，允许重试；程序不会在普通退出时自行安装。

下载只使用固定仓库 `xinghan1/Synora-code` 的版本安装包及 GitHub 官方下载域名，检查文件大小和 SHA-256，启动安装前再次核验。已下载缓存放在应用数据目录的 `updates` 下，重新下载时只有验证通过的缓存才会复用。开发运行和便携版可从本仓库 Releases 手动下载新版，不会直接替换便携目录或转换其数据位置。

更新检查与下载使用独立的 Chromium 网络会话，沿用系统代理，逐次核对 GitHub 官方下载跳转。代理连接、证书、DNS、连接中断及缓存磁盘空间或权限问题会分别提示。0.18.3–0.18.5 的旧更新器存在手动重定向兼容问题，即使代理正常也可能无法下载安装包；请手动下载并覆盖安装 0.18.6 或更新版本一次。

0.18.7 起，GitHub API 确认限流时会改从同一官方仓库的发布页面检查最新版，再读取同名 SHA-256 文件和安装包的精确大小，继续执行下载与安装前校验。成功检查结果短暂缓存 60 秒；限流期间按服务器提示暂缓 API 请求，避免反复点击检查继续消耗额度。该备用方式无需 GitHub 登录或令牌，不使用第三方镜像。

发布新版本时，将标签设为 `v版本号`（与 `package.json` 一致），上传 `Synora-code-Setup-版本号-x64.exe` 及同名 `.exe.sha256` 文件，并将正式 Release 设为 Latest。`npm run build:installer` 会同时生成安装包与校验文件，Windows Actions 的安装版 artifact 也包含这两个文件。只有上传源码、推送提交或上传 Actions artifact 不会触发客户端更新。需要先手动安装支持更新的版本，后续发布更高版本即可在软件内更新。

## 首次使用

通过独立的 **设置 → 宠物设置…** 管理 dsh-pet 宠物。内置透明动画，宠物可拖动、点击和右键操作，随思考、工具执行、等待、完成及错误切换动作；可调整大小、关闭状态联动、隐藏或恢复位置。内置宠物空闲时眼睛跟随鼠标，可单独关闭，执行动作、拖动或任务期间暂停跟随。配置自动保存并在重启后恢复，也可导入本机 dsh-pet JSON / JSONC 配置与其引用的 WebM 动画，素材会复制到应用数据目录；自定义宠物包沿用其原始动画。

通过独立的 **设置 → 插件管理…** 从本地文件夹安装插件，安装后先点击“启用”，再打开面板或运行其声明的命令。插件管理支持停用、移除和创建示例插件；“开发文档”打开随软件附带的接口说明，安装目录的 `开发者插件/` 包含文档、类型与示例。开发者使用 `synora-plugin.json` 清单和 HTML / CSS / JavaScript，在独立插件窗口中调用软件信息、项目文件列表、文本读取、带确认与版本检查的写入和通知接口。插件窗口绑定打开时的项目；切换项目后重新打开插件使用。源码说明见 [插件开发指南](docs/PLUGIN_DEVELOPMENT.md)。

通过顶部 **设置 → 模型分工** 配置子智能体、帮我批准、TAB 提示词补齐和侧边问答使用的模型。四项默认跟随当前主模型；只有成功保存该项独立配置后才启用专属模型，可随时“恢复跟随”。各项复用主模型设置表单，支持独立服务商、接口地址、API Key、模型目录或 ChatGPT 登录账号，重启后保留。独立账号登录与切换不会改变主会话账号；API Key 使用系统密钥库加密。旧版已手动选择的当前连接审批模型仍会保留，可在这里恢复跟随。

会话文字选中后，右键选择 **在侧边栏中提问**，选中文字会作为引用放入右侧临时问答；也可通过会话标题栏的问答图标或 **视图 → 侧边临时问答** 打开。输入问题后按 Enter 发送，Shift+Enter 换行。侧边问答可与主任务同时运行，只接收其自身问答及用户选中的引用，不执行项目操作。关闭侧栏只收起面板，保留本次运行中的临时问答，后台回复继续，重新打开可接着查看；退出软件时清空。内容不写入会话历史，仅独立累计模型回报的 Token 用量。

纯白风格使用浅灰背景与分层面板。通过 **外观 → 外观与背景… → 颜色风格** 可选择预设色板或自定义颜色，实时预览、自动保存，并可恢复默认。颜色统一应用于四种风格中的选中项、项目标识、输入框焦点边框、发送按钮、轮次标记、推理档位、窗口按钮，以及用量统计的活动色阶、选项和提示框；过暗或过亮的强调文字与图标使用同色系的清晰配色。

所有模型连接的会话助手统一以“Synora code”自称，子任务沿用相同身份。

安装后从快捷方式启动，或在便携版目录双击 `Synora code.exe`。默认界面采用蓝紫极光背景和圆角磨砂玻璃卡片。通过 **外观 → 外观与背景… → 界面风格** 可切换玻璃风、纯黑、纯白和工业风：纯黑与纯白使用不透明的简洁面板，三栏间距为 3px；工业风采用石墨灰、琥珀色强调，三栏紧贴并以单条分割线分隔。风格统一应用于三栏、会话、编辑器、菜单和弹窗，自动保存并在重启后恢复。玻璃风的背景、磨砂和字体配色独立保留，切回后恢复原设置。左上角保留透明 Logo、项目与菜单，项目下拉菜单集中打开项目和访问历史。模型选择位于输入框下方，空会话中的欢迎文字在对话区域内水平、垂直居中。

重新启动时，主窗口恢复上次选中的持久会话、项目和聊天标题，包括手动选中的较早历史会话。临时会话不覆盖恢复记录；项目或记录失效时安全回退到可用历史或新会话。恢复只打开已保存界面，不会自动继续模型、命令或待批准操作；另外新开的窗口仍从新会话开始。

在 **外观 → 外观与背景…** 中选择玻璃风、纯黑、纯白、工业风、DeepSeek 风或 Codex 风。后两种参考炭灰静蓝与中性柔和的材质、间距和圆角，保留 Synora code 的布局与功能。

通过 **外观 → 导入背景图…** 选择本机 PNG、JPEG 或 WebP 图片（最大 12 MB）。玻璃风应用于整个工作空间；纯黑、纯白、工业风、DeepSeek 风和 Codex 风只在中间会话区域显示图片，其他面板保留各自材质。输入框外侧留白、底部统计区域、工具操作和子任务条目透明显示会话背景，输入框及代码、输出详情保留各自材质底色。背景透明度实时调整，数值越大越淡；图片和设置自动保存，切换风格或重启后仍会保留。背景仅用于本机界面，不会作为附件或项目内容发送给模型。

同一设置内可直接选择蓝紫极光、玫瑰红、暖金、森林绿、海蓝、霜白、深夜黑、橙色、紫色、橄榄绿、粉色、品红、青色共十三种内置背景，无需导入图片。选择内置风格会切换掉当前导入图片，文字颜色、磨砂强度和透明度分别保留；这些渐变背景可适配不同屏幕尺寸。

**外观 → 外观与背景…** 内的“磨砂强度”统一调整左侧栏、中间会话区和右侧栏，范围为 0%–100%，0% 关闭背景模糊，数值越大越柔和。“面板透明度”单独控制三个区域的底色，0% 为不透明、100% 为透明，不降低文字和代码的不透明度；它与背景图片的透明度分别保存。恢复默认磨砂只复位磨砂强度，恢复默认背景只复位图片和背景透明度。旧版三栏独立强度会取平均值合并。`Alt+A` 可打开外观菜单。发送按钮采用纸飞机图标，保留 `Ctrl+Enter` 发送及运行中加入待发送列表的操作。

在 **外观 → 外观与背景… → 会话字体颜色** 中，可按背景图片搭配红、黄、绿、蓝、白或黑色文字，选择后即时生效并保存在本机；更换背景或重置磨砂不会改变已选文字颜色。模型的过程说明采用稍大的普通字重，文字后方不额外添加底色卡片，代码继续保留语法颜色。右侧文件编辑器支持多色语法高亮和左侧单列行号，行号随代码垂直滚动、横向固定，保留原有的编辑、选择、滚动和自动保存操作。

便携版从本机 Synora code 0.19.2、0.19.1、0.18.5、0.16.8、0.16.7、0.16.6、0.16.5、0.16.4、0.16.3、0.16.2、0.16.1、0.16.0、0.15.0、0.14.2、0.14.1、0.14.0、0.13、0.12、AI code 0.11、0.10、0.9、0.8、0.7、0.6、0.5 或 ForgeDesk 旧版升级：先关闭旧版，再打开新版本。若新版本数据目录尚未初始化，首次启动会从旁边的旧版本复制模型配置、会话、最近项目和用量记录，优先使用最新版本数据，并在启动前保留凭据依赖的本机加密状态及 ChatGPT 运行时标识；旧版数据保持原样。安装版更新继续使用 `%APPDATA%\Synora code\`，不受安装目录版本变化影响。

真实使用：

1. 通过左上角项目下拉菜单、“文件 → 打开文件夹…”（Ctrl + O）或侧栏“选择文件夹”，选择本地代码目录；优先恢复该项目上次选中的持久会话，没有可用选择时再打开最近有内容的聊天。
2. 通过推理卡片底部“模型设置”、“编辑 → 设置…”（Ctrl + ,）打开模型设置。OpenAI 可选 ChatGPT 账号授权或 API Key；DeepSeek、Claude 使用各自 API。第三方中转选择“中转站”，填写平台提供的 Base URL 和 API Key，默认使用 Chat Completions；平台明确支持 Responses 时可切换接口协议。本地或自建 Ollama 服务选择“Ollama · 本机 / 自建服务”，本机默认地址为 `http://localhost:11434`，无需 API Key。点击“获取 / 刷新”，从成功返回的目录选择模型后保存。获取目录会临时使用当前填写的配置，无需先保存密钥；失败或目录为空时不能保存，修改连接字段后需要重新获取。各服务商的配置和密钥分别保存，空白 Key 保留所选服务商已存 Key。
3. 点击输入框下方“模型 · 推理强度”打开卡片，拖动滑块选择强度，点击卡片中的模型名称选择版本。非满格为白色，拉到模型支持的最高档显示红橙渐变；重置按钮恢复默认。模型只能从目录选择，设置中不再显示模型 ID 输入框或推理强度选项，强度继续在输入框下方调整。然后输入任务，例如“先阅读项目结构，解释启动方式”。
4. 助手可读取与搜索文件。修改文件前展示原文和新文，执行命令前展示完整命令与工作目录，由你确认。
5. 可停止任务；“撤销上次修改”可恢复本次打开项目后由文件工具完成的上一次修改，撤销前仍需确认。如果文件已被其它程序修改，将拒绝覆盖。

## Ollama 本机和自建模型

先启动已有的 Ollama 服务，并准备支持工具调用的模型。Synora code 使用原生 `/api/tags`、`/api/show` 和 `/api/chat`，读取该服务已安装的模型及其工具、图片和思考能力，不会自动下载或安装模型。设置中的服务地址既可填本机 `http://localhost:11434`，也可填自建服务的 HTTP / HTTPS 地址或反向代理前缀；只有代理要求 Bearer 鉴权时才填写可选 API Key。接口与能力依据 [Ollama 官方 API](https://docs.ollama.com/api/introduction) 和 [工具调用说明](https://docs.ollama.com/capabilities/tool-calling)。

“模型上下文（Token）”默认 32,768，可在 4,096 至 2,097,152 之间调整，并受模型声明的训练容量限制。每次请求显式传入相同的 `num_ctx`，让自动压缩预算与实际请求一致；较大的窗口需要更多内存或显存。此设置与右下角自动压缩阈值分别保存，调整后需重新获取目录。支持流式回复、文件工具调用、用量回报、停止、当前连接内切换模型，以及独立 AI 审批。未声明编程工具能力的模型不能用作任务模型；明确支持文本的模型仍可用作审批模型，嵌入模型不能用作对话或审批模型。

## DeepSeek 账号与余额

选择 DeepSeek 模型时，推理档位卡片会按“最高／高／低／关闭”切换本地照片背景彩蛋，卡片尺寸不变，照片按卡片宽度缩放并上下居中。彩蛋仅用于界面显示，不会作为附件发送给模型。

DeepSeek 官方公开 API 采用 API Key 鉴权；已配置的 Key 关联对应开放平台账号。模型设置中选择 DeepSeek 后，可点击“查询余额”读取官方返回的可用状态、总余额、赠送余额与充值余额，或点击“打开官方账号”进入官方平台登录、查看和充值。该功能使用已保存的官方连接，不会自动查询，也不读取网页密码或 Cookie；它不是 ChatGPT 式的第三方账号授权登录。

余额查询仅适用于 `https://api.deepseek.com`（含 `/v1`），自定义中转仍使用各自配置，不能据此查询官方账户余额。参考 [DeepSeek 官方接入说明](https://api-docs.deepseek.com/) 与 [账户余额接口](https://api-docs.deepseek.com/api/get-user-balance/)。

## 当前功能

## Markdown、内置浏览器与操作权限

聊天回复与历史消息支持 Markdown 粗体、斜体、删除线、标题、列表、引用、代码和表格。代码块右上角提供复制按钮，复制完整原始代码并显示“已复制”反馈；流式回复和历史消息均支持，复制保留换行。HTML 标签不执行，Markdown 图片不自动联网加载。点击 HTTP(S) 链接在右侧内置浏览器打开。

通过“视图 → 浏览器”打开内置浏览器，支持地址栏、后退、前进、刷新和停止；当前项目的 HTML 文件可点击编辑器中的“网页预览”。AI 可读取页面可见文字及元素 selector，点击、填写和滚动；输入不会自动提交，不支持密码或文件输入。AI 访问 `.xml` 链接时会读取 XML 源文本，不打开网页；也可通过 `read_url` 分段读取网络 XML，项目内 XML 使用 `read_file`。网络读取保留审批、取消和大小限制，不执行脚本或外部实体。截图工具保存本机 PNG 并返回路径，不会把截图作为视觉输入交给模型。项目预览使用绑定 127.0.0.1、带随机地址的临时静态服务，检查项目边界与受保护路径。网页没有应用桥接或 Node 权限，使用独立临时浏览会话，禁止弹窗、下载和设备权限。各项目拥有独立页面和预览服务；切换时隐藏后台页面，后台浏览器操作不会占用当前项目的面板。

输入框下方的权限菜单提供：

- **请求批准**：文件修改、命令及网页操作先展示确认；只读页面快照不需要审批。
- **帮我批准**：经现有低风险校验的项目文本修改、少量简单只读命令、本地导航及滚动直接通过；其余操作交给独立 AI，按真实任务目标直接允许或拒绝。目标范围内常规增删改文件、重构、构建测试和页面验证默认允许，不要求逐个文件或步骤再次确认；泄密、广域破坏和明显越权操作拒绝。超时、失败、内容不完整或无法判断时拒绝，不转人工、不自动重试；拒绝理由返回原任务。审批 AI 没有文件、命令或浏览器工具，不执行待审操作。权限菜单可选择审批模型，默认使用当前模型的独立上下文，也可单独选择当前连接目录中的文字模型；额外请求的已回报 Token 计入当前会话用量。
- **完全控制**：先弹出居中风险确认窗口，确认后自动批准现有工具的文件修改、命令和网页操作。终端命令以 Windows 当前用户权限执行，没有系统沙箱。

三种权限选择均按项目保存在本机，重新打开同一项目或重启软件后恢复上次保存的模式；首次打开未设置的项目默认为“请求批准”。当前窗口切换权限不改变其他已打开窗口正在使用的权限。未打开项目时的选择单独保存。保存失败会显示提示并保留之前的权限，不会显示保存成功。设置位于应用数据目录的 `permission-preferences.json`，不存放在项目源码内。

AI 审批会结合原始目标和后续补充理解“继续”，不会要求再次逐项指定常规开发步骤。任务相关的本地测试配置修改、探测程序、启动测试服务、清理本次测试产物，以及停止本次启动并记录的进程均可按目标批准。较长会话会保留原始目标、最近要求及限制的完整原文，避免仅因历史过长而拒绝；不会以助手回复或压缩摘要代替用户授权。

审批模型选择也按项目和模型连接保存在本机，重新打开同一项目或重启后恢复；“跟随当前模型”同样会保存。当前窗口修改不会改变其他已打开窗口正在使用的审批模型；新窗口读取最后保存的选择。不同服务商、API 地址、密钥或 ChatGPT 账号分别记录，不会套用其他连接的审批模型。设置位于应用数据目录的 `approval-reviewer-preferences.json`，仅保存项目、连接标识哈希及模型名，不保存密钥原文。保存失败会提示并保持原选择。

模型运行时和有待发送消息时也能切换权限，待执行的审批立即按新模式处理；已启动的操作不会撤销。更改权限或审批模型会取消旧 AI 审查，旧结果不能放行操作。停止任务会同时取消审批请求和等待中的 AI 审查。

运行中可从当前连接的模型目录选择其他模型或推理强度；已发出的请求继续使用原快照，下一次模型请求（包括子任务）开始使用新选择。切换到较小上下文模型时会先重新规划、必要时压缩；完整历史保留。更换服务商、API 地址、密钥、登录方式或 ChatGPT 账号仍需先停止任务。

模型临时断线、连接超时或服务繁忙时，自动尝试重连最多 5 次，并在会话中显示次数和等待时间；停止按钮可随时取消。流式回复中途断开时，清除该次未完成片段，重新请求当前回复，已完成的文件、命令和其他工具操作不会重新执行。认证、无效请求、额度不足或响应格式错误直接报告；服务商要求较长冷却时间时不提前重试。每次模型请求分别记录已回报用量，缺失部分不计为实测。

文件工具已有的项目范围、凭据保护与并发版本检查不会因权限档位解除。手动编辑仍直接自动保存。

## 自动压缩上下文

点击右下角的圆形进度条或百分比可展开自动压缩设置，默认阈值为 **850,000 Token**，支持输入 1,000 至 16,000,000 之间的整数，也可恢复默认。设置保存在本机，在各窗口和项目之间同步，重启保留；运行中调整会在下一次模型请求规划时生效。

较长对话、代码分析、命令输出及任务进度会积累上下文。每次发送前检查当前活动上下文：存在同一模型、连接、窗口及相同消息前缀的服务端实测数据时，总窗口以上次实际输入与输出之和为基准，输入窗口仅使用实际输入，再估算新增内容的增长；前缀、工具定义或连接不匹配时回退到内部保守预算，包含必要系统提示、工具定义和原生状态。达到阈值后通过当前模型生成精简工作摘要，保留原始目标、最新要求、约束、关键文件路径、已完成的操作、验证结果及待办，再继续编程；不会按整段会话累计消耗的 Token 触发。模型容量较小时，实际阈值受安全输入预算限制而提前触发；容量未知时仍使用保守估算与字符护栏。阈值过低时也会保留必需的提示和任务目标，避免仅因偏好设置使可执行任务失败或反复压缩。

ChatGPT 登录保留官方目录返回的有效容量；目录未给出容量时，仅为已核实的官方型号使用其公开窗口。比如 [GPT-6.1-Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) 的窗口为 1,050,000 Token，默认 850,000 的压缩偏好受本应用安全预算限制，实际触发点为 840,000；不会因登录链路遗漏容量而误用 45,000 的未知模型护栏。官方返回更小的账号容量时以该值为准。自动压缩取决于当前上下文占用，不固定等待两三轮对话。

Codex 官方公开的 `model_auto_compact_token_limit` 是活动上下文的压缩阈值，未设置采用模型默认；`scope=total` 统计完整活动上下文，`body_after_prefix` 则统计保留前缀之后的增长量，见 [Codex 配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)。官方没有统一“80%触发”规则。Synora 保留自己的跨服务商安全预算，摘要由当前连接的模型生成，并不宣称与 Codex 的内部实现完全一致。OpenAI 的 [Responses 精确计数接口](https://developers.openai.com/api/docs/guides/token-counting) 可在请求前计数；Ollama 等尚未接入此精确预计数接口的连接，Synora 等待实际请求回报，不为显示数字额外发送生成请求。

压缩期间显示“正在压缩上下文…”，成功后显示“上下文已自动压缩”。原聊天记录、消息时间、图片及工具结果不会被删除；仅发送给模型的内容使用摘要与保留的近期记录。需要精确代码时，助手可重新读取项目文件。

摘要只使用公开消息与工具结果，不发送原生私有推理作为总结材料，不授予新权限，也不执行工具。保留的工具批次和原生推理状态保持完整；历史图片仍以图片附件保留，原有图片数量及大小限制继续适用。摘要请求的实际 Token 单独计入现有用量统计。

摘要保存后可在后续任务及恢复历史时复用。压缩期间可停止；停止或摘要失败时不使用未完成的摘要，已有文件改动及待发送消息保持原有规则。模型服务本身的上下文及请求限制仍然有效。

## 消息气泡与图片

输入框旁的图片按钮可选择截图或照片，也可在输入框粘贴截图。每条消息最多 4 张，支持 PNG、JPEG、WebP，每张最多 2 MiB、单边不超过 8192 像素且总像素不超过 2000 万，合计最多 8 MiB；发送前可移除附件，也可只发送图片。图片会作为对应模型协议的图片内容发送，不会当作一串文字编码交给模型。目录明确不支持图片的模型会拒绝发送；未声明图片能力的接口由服务端确认支持情况。

消息正文显示在右侧气泡，图片缩略图显示在其上方靠右。气泡下方的时间按香港时间显示，记录点击发送时的时间，排队后保留原时间；旧历史没有时间字段时不补造。复制按钮只复制正文，不包含时间或图片，复制成功会显示反馈。

会话正文支持用鼠标左键拖动选择文字，右键提供“复制”“选择全部”“搜索浏览器”。全选仅选中当前会话；搜索使用选中文字，在右侧内置浏览器中打开 Bing 搜索结果。

运行中发送的图片会随待发送消息保留，直到该消息真正发送或被移除。图片随会话保存在本机 JSON 历史中；临时聊天仍遵循不保存历史的规则。为控制单次请求大小，包含历史在内，每次模型请求最多携带 32 张图片、解码后合计 16 MiB；超过时需新建聊天，不会自动丢弃图片。

## 文件资源管理器与自动保存

模型运行、等待审批或存在待发送消息时，仍可打开文件、打开文件所在位置、新建文件和文件夹、剪切、复制、粘贴、复制路径、重命名、删除及编辑自动保存。文件操作不会停止模型任务；保存和文件操作期间会短暂锁定相关操作。若模型与编辑器修改同一文件，继续使用文件版本检查，检测到冲突时保留当前内容并提示重新读取或合并。

助手的文件工具支持当前项目相对路径、指向其他目录的 `../` 路径，以及完整本机绝对路径，例如 `G:/plugin/server/src/Main.java`。在任务中说明另一个目录的位置和需要完成的工作，就可以直接读取、搜索、创建或修改关联项目的文件，无需切换当前项目。当前项目仍作为相对路径和命令的默认工作目录；外部修改按现有权限模式审批，AI 审批依据真实任务范围判断。

通过 **文件 → 打开文件…（Ctrl+Shift+O）**，也可以在右侧编辑器打开其他目录中的文本文件。外部文件标题显示完整地址，支持自动保存及保存冲突检查；左侧项目不切换，文件树的移动、删除和批量操作仍针对当前项目。助手修改外部文件的实际快照会加入当前任务的变更汇总，历史会话及软件重启后的撤销、取消撤销同样可用；外部文件被其他程序修改后拒绝覆盖。

左侧栏始终显示项目文件树，不再提供“文件／历史”切换。展开文件夹后，点击文件在右侧编辑；顶部按钮可新建文件或文件夹，右键菜单提供打开、新建、重命名、删除、剪切、复制、粘贴与路径复制。剪切和复制使用当前窗口内部的文件剪贴板；路径复制写入系统剪贴板。删除前确认，完成后可从 Windows 回收站恢复。同目录复制会自动添加“副本”后缀，剪切遇到同名目标会拒绝覆盖。

按住 Ctrl 点击可逐项添加或取消选择，Shift 点击可按当前可见顺序连续多选；支持 Ctrl+A 与 Shift+方向键。空白区域按住左键拖动可框选，在文件行上长按约 350ms 后拖动也可框选，靠近边缘会自动滚动，Esc 可取消此次框选。修饰键多选不会打开文件或展开目录，右键已选项会保留多选。多项可批量复制、剪切、粘贴、移动、删除和复制路径，选中的父目录及其子项只操作一次，删除合并确认；重命名和打开所在位置仅用于单项。快速拖动文件行仍用于移动文件。

可将文件或文件夹拖到另一文件夹上移动，目标会高亮；拖到左侧项目名称可移回项目根目录。同名目标会阻止移动，文件夹不能移入自身或子目录。移动前会保存编辑内容，并同步更新已打开文件和内部剪贴板的路径。

点击左下角整个 **Token 用量** 卡片，可在会话中间打开本机统计：累计 Token、单日峰值、最长任务用时、最长及当前连续活跃天数，以及最近 365 天的活动热力图。支持每日、每周和累计视图，悬停或用键盘选择色块可查看详细用量。统计沿用本机账本，包含所有项目已回报的输入和输出；缺失、部分报告及旧版近似记录会说明。关闭后返回原会话，输入草稿保留。

会话区左上角显示当前会话标题，默认采用第一条任务内容。点击标题下拉菜单中的 **重命名会话…** 可保存自定义标题（最多 80 个字符）；自定义名称不会被后续消息覆盖。项目选择器和资源管理器仍显示项目名称。

会话列表每条记录右侧有删除按钮，确认后删除该会话及其撤销记录；删除当前会话会切换到该项目的其他历史，没有历史时新建会话。正在处理任务的会话需结束任务后删除。最近项目右侧的删除按钮用于移除列表记录，重新打开该项目会再次显示在最近列表中。

文件编辑器默认自动保存：停止输入约半秒后写入文件，状态栏显示保存状态；Ctrl + S 可立即保存。保存期间继续输入的内容会接着保存，切换文件、项目或关闭窗口前会先完成保存。遇到外部修改、权限或写入错误时，自动保存暂停并保留当前编辑内容；离开前可取消或放弃编辑，不会自动覆盖检测到的外部改动。手动编辑直接写入所选文件，不经过模型审批，也不计入助手的“撤销上次修改”。

Markdown 文件（`.md`、`.markdown`）支持源代码颜色高亮，包括标题、列表、引用、链接、行内代码和围栏代码块。围栏代码按标注的 JavaScript、Python、JSON 等语言上色；未标注或不支持的语言保留原文。高亮仅改变显示，编辑、选中和复制仍使用原始文本；超大文件保留可编辑的普通文本显示。

编辑支持不超过 512 KiB 的 UTF-8 文本。文件复制保留二进制内容，单次目录操作最多 2000 项、深度 40 层，复制总量最多 128 MiB；文件树每层最多显示 500 项。文件管理与助手工具共用项目路径保护规则，不访问链接、联接或受保护的凭据目录；目录操作发现受保护的子项时会取消。

## 待发送与引导

模型运行期间，输入框、发送和停止按钮保持可用。点击发送（或 Ctrl + Enter）后，消息以简洁的单行显示在输入框上方，不显示数量标题、计费说明或自动发送说明；当前任务正常结束后，逐条发起后续任务。单行保留引导、编辑、删除和“…”全文查看，图片使用可点击的小缩略图。编辑仅修改尚未发送的正文，保留原附件、顺序和发送方式；已经应用的内容不能回写修改。消息真正发送前不会加入模型上下文、会话历史或 Token 用量。

点击单行上的“引导”，会将这条补充要求交给当前任务。正在进行的模型响应、工具执行和确认请求会继续；引导在当前模型请求结束、整批工具结果齐全之后加入下一次模型调用。已应用的引导显示在当时的操作进度位置，历史恢复保持原时序，后续排队任务仍独立显示。已经生成的输出会保留。任务结束时，尚未应用的引导转回待发送，在后续任务处理。

停止任务或发生错误后，待发送列表暂停并保留消息，点击“继续发送”才恢复。可随时移除尚未应用的消息。每个窗口中各项目的队列独立，仅保存在内存中，最多 20 条、每条最多 40000 字符；关闭窗口后不会恢复。队列在后台仍可顺序发送；切换本项目的历史会话或修改共享连接配置前，需先处理其待发送消息。临时聊天中的队列遵循临时聊天的历史保存规则。

## 选择模型与排查 DeepSeek 错误

在设置中填写 API Key 与地址后，先获取模型目录，再选择模型并保存。选中时会保存接口返回的真实 ID，不会将展示名作为 API 参数。自定义代理需提供对应协议的模型目录接口；未取得可选目录时不能保存，配置变更或目录凭证过期后需重新获取。目录获取本身不会保存配置或发起推理请求。模型目录只表示服务返回的清单，不保证该模型具有工具调用能力、剩余额度或当次推理权限。明确不支持工具的模型不可用于编程任务；能力未知时会注明。

### 中转站与 HTTP 404

“中转站”拥有独立的地址、密钥和模型设置，默认使用 Chat Completions。Base URL 填平台给出的基础地址，例如 `https://你的平台/v1`；软件会按所选协议追加 `/chat/completions` 或 `/responses`。如果平台提供的是完整请求地址，应选择与其后缀一致的协议。`/models` 后缀会自动归一化；不同协议的请求后缀会在本地提示不匹配，避免拼出双重路径。

模型目录使用 `GET /models`，模型推理使用对应的 `POST` 接口，因此“能获取模型列表”不保证该平台提供所选推理接口或该模型的调用权限。404 会显示实际协议和脱敏后的请求路径，软件不会自动切换协议或重复请求。

若服务端明确返回 `not supported by any configured account in this group` 或当前分组无可用渠道，软件会单独提示分组的上游模型配置不可用。请在中转站后台确认当前 Key 所属分组、该分组实际支持的模型及请求协议，必要时联系平台配置账号或模型映射；调整推理强度无法补齐这些配置。通用 `Resource not found` 只能说明当前路由、资源或模型不可用，软件不会把它直接断定为某一种协议错误。收到模型分组错误也不等于已经成功生成模型回复。

升级后，已有 OpenAI API 配置保留 Responses。若原先的中转只提供 Chat Completions，可在已有 OpenAI 配置中切换“接口协议”后保存，密钥留空即可保留；也可以新建独立的“中转站”配置。ChatGPT 账号模式始终使用 OpenAI 官方 Responses。

目录缓存按服务商、API 地址与凭据隔离；ChatGPT 按账号隔离。推理强度默认开放通用档位：OpenAI 和中转站 7 档，DeepSeek 4 档，Claude 5 档；初始“默认”遵从服务商设置，只有手动选定具体档位才发送对应参数。尚未取得能力信息时仍可调节，通用档位是否被实际模型接受由接口决定。

获取或刷新目录后，明确提供的模型档位会替换通用档位，例如低／中／高 3 档或其它 5 档；如果原先选择不在新列表中，会自动恢复“默认”。目录明确声明不支持调节时才显示“不可用”并禁用滑块，使用服务商默认设置。刷新失败或没有档位信息时，仍保留通用选择。模型 ID 中的 `high`、`low` 等后缀保持原样，不会据此猜测可调档位；软件不自动探测或重复推理请求。

### 工具参数 JSON 错误

0.16.8 兼容中转站直接返回对象形式的工具参数，并修复空的完成快照覆盖已接收有效参数的问题。明确的完整快照会核对调用身份和参数一致性，保存与回放时使用标准 JSON 字符串。

若模型真的返回空参数、非法转义、截断内容或冲突快照，软件仍会停止当前批次工具，并提示协议、已注册的工具名称和错误类别。错误信息不包含原始参数或代码。已完成的早期操作与会话记录会保留；确认后可重新发送要求继续任务。

### 中转站与 HTTP 524

HTTP 524 表示 Cloudflare 已连接上游，但未及时得到响应，常见原因是中转服务器或模型处理时间过长。获取模型目录成功不能证明推理接口能及时返回，524 也不能单独证明是推理强度参数错误。客户端延长等待时间无法解除上游的超时；可换用同平台其他可用模型，或联系中转站检查上游路由、负载和流式响应。软件不会为此自动重试，避免重复调用。

参考：[Cloudflare Error 524](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/cloudflare-5xx-errors/error-524/)。

DeepSeek 的发布名称（例如 `DeepSeek-V4.1-Flash-1017`）与 API 模型 ID 不同。请获取目录并选择接口返回的 `deepseek-flash` 等 ID，具体清单以当前账号和服务地址为准。HTTP 400 会显示经过脱敏的服务端错误、字段或错误代码；不会自动重试产生额外调用。如果错误指向旧会话的推理历史，先新建对话，再使用所选模型继续。

0.8 调整了长推理、代码生成时的流式接收限制：SSE 默认传输预算为 64 MiB，单个事件为 8 MiB，实际模型内容与原生状态合计为 16 MiB；普通 JSON 响应仍为 8 MiB。流式协议元数据和保活消息不会重复占用模型内容预算。触及保护上限时会停止接收并提示分步生成，不会自动重试或降低推理强度。旧版因接收大小失败的任务，升级后需重新发送。

0.10 将模型请求的固定 120 秒超时改为网络无数据超时。默认连续 10 分钟没有收到响应数据才停止；思考数据、正文、工具参数和保活数据都会刷新等待时间，持续返回数据的请求不再受固定总时长限制。等待响应头也使用相同预算；停止按钮可随时取消。此调整不改变 PowerShell 命令自身的执行时限，也不会自动重试请求。

## 使用 DeepSeek 账号

在模型设置中选择 DeepSeek，将连接方式切换为“DeepSeek 账号”，点击登录后在系统浏览器的官方页面完成授权，再获取账号模型目录、选择模型并保存。账号模型目录以官方实际返回的 Messages 接口能力为准；登录失败、取消、失效和本机保存错误会分别显示，可重新连接或退出账号。

授权使用官方公开的浏览器 PKCE 流程，凭据由 Windows 加密后保存到本机数据目录的 `deepseek-account.json`。主模型与各项模型分工可分别登录，互不共享凭据；API Key 方式独立保留。登录、目录与模型请求沿用系统代理，仅连接固定官方授权及推理地址。切换账号或重新授权后会取消旧账号的补全和目录选择，下次任务建立新的会话，避免把旧账号会话发送给新账号。

接入协议依据 [DeepSeek Harness 官方实现](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/credentials/deepseek-account-platform)，相关来源与 MIT 许可随程序保留。可访问模型、权限、额度及计费由 DeepSeek 官方账号决定。

## 使用 ChatGPT 账号

在 OpenAI 设置中选择 ChatGPT 连接方式，点击 `Continue with ChatGPT`。应用会打开官方授权页面，由你在浏览器完成登录和套餐授权。应用不接收账号密码、不读取浏览器 Cookie 或 ChatGPT 聊天记录。可保存多个连接、切换账号、重新授权、退出和打开官方用量设置。

符合资格的 Plus／Pro 账号可授权本地个人应用使用 ChatGPT 套餐，无需填写 API Key。身份登录与套餐使用权限分开：只有已连接且授予套餐用量权限时，应用才会发起模型请求。模型目录以账号返回为准，完成一次请求才验证当次模型访问权限；实际额度和限制以 ChatGPT 账号及官方设置为准。额度不足或授权撤销时会明确报错，不自动切换到 API 计费。

模型设置内保留打开 ChatGPT 官方用量页面的入口，用于查看实际额度及应用限制。输入区的“使用情况”按钮与弹窗已移除，服务商明确回报的用量仍计入本机统计。

授权令牌由官方 SDK 管理，使用 Windows 本机加密保存在本机数据目录下的 `chatgpt/`（安装版为 `%APPDATA%\Synora code\chatgpt\`，便携版为 EXE 同级 `data\chatgpt\`），只在主进程用于固定的官方服务地址。退出时尝试撤销远程会话；未能确认远程撤销时会提示你到 ChatGPT 设置断开应用。切换 ChatGPT 账号会在下次任务创建新对话；加载其它账号的旧历史也不会将上下文发送给当前账号。API Key 与 ChatGPT 模式分别记住模型，API 自定义地址和密钥会保留。

0.16.5 修复了旧版升级时遗漏凭据加密状态的问题：在 Electron 加载加密密钥前，仅迁移数据目录内 `chromium/Local State` 中的 `os_crypt`，不复制浏览器 Cookie 或缓存，也不覆盖新目录已有的不同密钥。原本已经无法读取的登录文件会显示“本机登录信息读取失败”，可先点“重试读取”；此操作只读本地，不发起浏览器授权或模型请求。若仍无法恢复，点击“退出账号”会在 SDK 同一文件锁下，将原密文保存在数据目录内 `chatgpt/.chatgpt-preserved-*/chatgpt-auth.json`，然后解除本机连接。由于无法读取原凭据，此时不能确认远程撤销，需到官方页面管理授权；之后可重新登录一次。此恢复只会在明确点击退出时执行，正常启动、模型切换或读取失败不会自动重置账号。

此账号接入使用 OpenAI Sign-in with ChatGPT DevKit，遵循随程序附带的非商业许可，当前供本机个人实验使用。商业、收费或远程托管用途需另行确认 OpenAI 接入资格与组件许可。许可原文位于 `src/vendor/siwc/LICENSE`；只扩展主进程回调接口，OAuth、身份验证、权限校验和刷新仍由官方代码负责。未登录真实账号时，测试仅验证本机模拟授权及协议，不能证明你的账号一定具备访问资格。

## Token 用量与速度

每轮任务结束后，回复下方显示该轮实际回报的用量，例如“用量 9.7K tok”，历史会话重新打开后仍保留。单轮累计输入与输出，包含工具续答、自动压缩、子任务、AI 审批和重连请求；缓存及推理 Token 不重复计算。悬停可查看输入、输出和报告覆盖范围，部分回报加星号，完全缺失显示“未回报”；不使用回复长度估算。旧历史缺少可信轮次关联时不会强行归属。

输入框下方的当前会话统计与服务商信息共用一行，在右侧对齐，替代原先的代码检查提示，不再显示独立卡片；窄窗口会自动换行。对话轮数只计算已实际进入会话的用户消息，待发送消息不计入。累计 Token 来自本应用各次模型请求回报的输入与输出，包含工具调用循环和自动压缩请求；缓存及推理用量已包含在相应数字中，不重复相加。

缓存命中率使用服务商明确回报的缓存输入 Token 计算。未提供数据时以“0”占位；部分请求缺少用量时，以星号和悬停说明标明统计范围。切换项目或恢复会话时，统计跟随相应会话。

上下文圆环的实际占用比例使用服务端实测数据：总上下文窗口按最近完成请求的实际输入加输出计算，缓存和思考属于分项，不重复累加；若目录声明的是输入上限，则只比较实际输入。悬停可查看输入、输出、容量及统计依据。新增内容尚待回报时，圆环保留最近完整实测值，并明确说明不是当前新增内容的测量；没有任何匹配的完整样本时才显示“0%”占位。模型、服务商或连接切换后不复用旧值；没有有效容量时不计算实际百分比。展示保留值不参与当前请求的严格测量状态，也不改变自动压缩预算。自动压缩改变请求内容后等待服务端重新测量，累计消耗仍保留。

模型目录提供有效容量时，Synora 在设定阈值与约 80% 模型容量中取较小值触发，并依据有效预算保留近期原文；实测基准之后的新增内容仍属估计，不能将整个下一请求预算称为精确分词。目录没有容量时还会使用约 45,000 个估算 Token 和 18 万字符的保守护栏。悬停“上下文已自动压缩”可查看本次触发依据。会话累计 Token 会重复计入多轮请求发送的历史、缓存输入和摘要请求，不能用它判断当前上下文是否已满。

自动压缩期间，会话当前位置显示“正在压缩上下文 · 可能需要几分钟”，重新打开运行中界面也能恢复提示。完成后显示压缩完成状态，停止或失败会结束等待提示。大量工具记录的压缩规划使用安全批次边界查找，减少开始请求前的界面等待；原始聊天、图片与完整工具记录继续保留。“正在思考”、压缩以及读取文件、运行命令、搜索等正在执行的操作文字带有从左向右扫过的亮光，单项和折叠分组都按实际状态更新，完成、失败或停止后结束动画；系统开启“减少动态效果”时关闭动画。

侧栏 Token 统计区仅展示今日、本周、本月的用量；底部不再显示“香港时间 · 每周一开始”、用量不完整请求计数或“统计说明”折叠项。

日、周、月按 `Asia/Hong_Kong`（香港时间）划分：每日 00:00、每周一 00:00、每月 1 日 00:00。统计来自此应用调用 API 时服务商返回的输入与输出 Token，缓存及推理用量依照服务商 usage 合并，推理 Token 不会再次重复相加。统计是本机用量记录，不是账户总账或费用账单。每次模型请求按完成时间记一笔，工具调用循环的各轮请求分别累计。

对话中的任务状态显示“正在思考”“正在读取文件”“正在运行命令”等活动，不展示模型的私有推理正文。每项操作可单独展开；命令以可读的中文状态和分区输出显示，技术参数与原始结果还需点击“查看详情”或“原始数据”才展示。大量命令日志仅保留有界的首尾预览，省略处明确标记，不因日志量大而停止命令；错误保持简短状态提示，已保留的详细堆栈可展开查看。模型回复中的正常代码示例仍会显示，并按语法着色。审批请求在底部输入区域显示，完整命令和详情可展开并滚动，批准／拒绝按钮保持可见。

输入框的 Tab 补全使用当前模型，根据近期公开会话文字和当前草稿追加下一条提示词，不读取项目文件、不调用工具，也不增加对话轮次。补全请求的服务商用量独立记入本机统计，不计入正在执行的任务；新会话和草稿均为空时提供本地起始建议。补全时继续输入、移动光标、按 Esc、切换会话或更换模型会丢弃旧建议，避免覆盖新内容。Shift+Tab 保留原有焦点导航。

每轮对话顶部的折叠栏只显示“用时 21分钟 48秒”和展开箭头，运行中持续计时。思考、等待和重连状态显示在会话流程当前位置，文件读取、命令、搜索等由对应操作行或分组显示。任务完成、停止或失败后，操作过程默认收起，点击用时栏可重新展开；模型的最终回复保留在折叠栏下方，未完成的流式内容保留在过程内。时长包含模型请求、工具执行和等待确认，任务结束后停止增长。重新打开历史会话时可恢复已保存的操作与结果，历史批准请求不再显示为消息或可操作选项；旧记录缺少分组或时长信息时保留原消息，不估造过程与用时。

文件差异取自实际成功写入前后的内容，不把批准提案当作已执行结果，也不把本地差异快照加入模型上下文。会话独立保留最近 64 次编辑快照，总字符数上限为 `8 × 1024 × 1024`；超大改动的预览会明确提示整段替换或省略，复制按钮仍复制完整的修改后内容（删除文件时复制删除前内容）。

每轮任务结束后，有文件改动时在回复下方显示变更汇总：文件数量、合计新增／删除行数，以及各文件的路径和统计。同一文件的连续多次写入合并为本轮开始至结束的净变化；每个文件只显示一条目录行，点击后在该行下方展开代码差异；默认显示三个文件，其余可展开。“查看变更”打开本卡的差异预览。“撤销”恢复本轮修改前的文件，“取消撤销”重新应用已撤销的修改；两者均遵循现有审批规则，只更新原变更卡片状态，不额外生成“用时 0s”或“任务已完成”消息。每个文件执行前重新核对内容，冲突时保留当前文件，取消或失败会明确报告已经完成的部分。

撤销原始快照和方向状态使用 Windows 本机加密，按会话保存在数据目录的 `task-undo/`，重启、打开历史会话后仍可撤销或恢复；临时会话不落盘。旧记录只有在快照完整、连续且未经脱敏时才导入，已经丢失或脱敏的原始内容无法补回。撤销快照和写入日志均不发送给模型；命令自行修改的文件不计入助手文件工具的快照。写前记录和提交状态采用原子保存，若异常退出留下不确定操作或记录损坏，则保留文件并停用相应自动操作。

项目、会话、模型、权限、菜单及设置中的下拉选择统一按位置向上或向下逐渐拉开，收起时反向合拢，文字保持原尺寸。设置选择框保留原有值、键盘和表单行为，选项使用应用内浮层展示；开启系统“减少动态效果”时直接切换。

连续多条搜索操作会合并到一个默认收起的“已完成搜索”分组，手动展开查看每次搜索及其结果。分组支持实时过程和历史恢复，不跨越模型说明、引导消息或任务边界。

会话统计行中的 `≈ tok/s` 为估算：按流式正文、工具参数和服务商可见推理片段的字符量估算 Token；隐藏推理无法实时精确计数。请求结束后用 API 回报的输出 Token 数与模型请求总耗时校准平均速度。速度的计算耗时包含等待响应和网络时间，不包含本地工具执行或用户审批，与任务总时长分别计算。等待、审批或执行工具时不沿用上一请求的实时速度；没有有效速度时显示“0”。估算不计入本机用量账本。

取消、断流、超时也可能已消耗 Token。应用会保存服务商已回报的数字及用量是否完整的记录，侧栏不额外显示提示；没有回报的数字不会用估算数充当实际用量。旧版会话只能恢复保留下来的累计用量，并按会话最后保存时间归档；旧记录被截断的部分无法补回。

## 子智能体协作

复杂任务可以交给多个子智能体并行处理，例如：“让两个子智能体分别检查前端和后端，最后汇总问题。”主助手可以继续自己的独立工作，并在最终回复前收集子任务结果。每次主任务最多同时运行 3 个、累计创建 8 个子智能体，子智能体不能继续委派。

会话中的彩色图标行显示子任务名称和实际状态，点击可查看任务、公开操作和结果；运行中可单独停止，也可以通过底部停止按钮一起取消主任务及全部子任务。历史会话保留已保存的状态与结果，打开历史不会重新执行。子任务拥有独立上下文，模型选择与主任务一致，运行中切换从各自下一次请求生效；每次额外模型请求的已回报 Token 都计入当前会话与本机用量。

子任务默认只读。需要修改时，主助手必须分配明确的文件或目录写入范围，可使用项目相对路径或项目外完整绝对路径，目录范围以 `/` 结尾。活跃子任务的范围不能重叠，相对路径与同一文件的绝对路径按同一位置检查；文件修改和命令继续遵循现有权限与审批规则，审批会标明子任务名称。写入范围仅约束文件工具，命令仍以当前 Windows 用户权限执行。停止任务不会撤销已经完成的修改；子任务通过文件工具完成的修改会加入当前项目的助手撤销记录。

## 数据与执行边界

安装版设置、加密密钥、会话和 Chromium 缓存保存在 `%APPDATA%\Synora code\`；便携版保存在 EXE 同级 `data\`；开发运行保存在项目 `.local-data/`。会话和工具记录以普通 JSON 保存，可能包含项目源码与命令输出。请妥善管理这些本机文件。

模型请求会把任务、会话及相关文件/工具内容发送到设置中选择的 API 地址。自定义地址会收到相应供应商的 API Key，请只填写你信任的服务。应用不提供模型账户、额度或订阅，也未内置 API Key。

文件工具限制在所选项目，拒绝路径穿越、符号链接、Windows 联接和常见凭据路径。**确认后的 PowerShell 命令使用当前 Windows 用户权限，不具有操作系统沙箱**，可以访问项目目录以外的位置。请在确认界面审阅完整命令。

撤销只覆盖助手文件工具的修改，不覆盖手动编辑与终端命令产生的变化。任务卡中的撤销与恢复使用已保存快照，重启后可用；菜单“撤销上次修改”与模型的单步撤销工具仍针对本次打开项目后的操作。助手文本工具和编辑器仅支持 UTF-8 文本文件，单文件上限 512 KiB。搜索跳过依赖、隐藏目录和构建产物。较长会话会自动压缩发送上下文，完整本地历史保留。

这是可运行的本地单用户基础版，尚不含语言服务器、Git 分支管理或代码签名。未使用真实账号或 API Key 时，只能验证模拟协议与本机工具流程，无法确认账户权限、额度和实际模型效果。

## 开发与构建

环境：Windows x64、Node.js 22.12+、npm。

```powershell
npm.cmd ci
npm.cmd run prepare:sdk
npm.cmd start
npm.cmd test
npm.cmd run smoke
npm.cmd run build
npm.cmd run build:installer
```

Electron 首次安装依赖时需下载官方桌面运行时。`npm run smoke` 在隐藏窗口执行真实渲染、IPC、审批、推理参数及 Token 账本验证，并在 `artifacts/` 输出截图及结果。离线演示仅保留用于内部测试，不占用主界面。`npm run build` 生成 `dist/Synora-code-版本号-win32-x64/`，不会覆盖已存在的便携目录，以免损坏本地数据。`npm run build:installer` 通过 electron-builder / NSIS 生成 `installer-output/Synora-code-Setup-版本号-x64.exe`，不自动运行安装器或发布 Release。
