# Cortex Android

二维码扫描使用 ZXing Core 3.5.3（Apache License 2.0），许可证随应用打包，详见仓库的第三方组件说明。

Android 8.0（API 26）及以上的原生客户端。手机模式将多个会话保存到设备，支持在侧栏搜索和切换，并可配置多个 OpenAI Chat Completions 兼容 HTTPS 模型或 Anthropic Messages API 模型。支持通过系统浏览器授权 DeepSeek 账号；其他服务商的手机原生账号登录尚未实现，可使用 API Key 或连接电脑使用电脑已登录的账号。模型支持工具调用时，可使用系统文件夹选择器授权的目录列目录、读取和写入文本文件（单文件最多 1 MiB）。手机上的工具只访问授权目录；它不运行电脑端 shell 或官方 CLI。

会话支持常用 Markdown、代码着色和展开查看工具调用、输入及结果。输入区可以选择工作空间、模型和附件：附件每次一个，图片发送前会缩放压缩，文件目前支持最多 15 KB 的 UTF-8 文本（包括 Markdown）。可调思考强度仅对已识别支持该参数的本机模型开放。

手机本地使用兼容服务的流式响应逐步显示回复；服务返回普通 JSON 时按其返回方式显示。连接电脑时，任务运行期间会更频繁地同步电脑的生成内容。模型设置中的模型必须从当前连接的模型目录选择；已有配置可在连接未更改时离线保留。

电脑模式连接桌面 Cortex 启用的手机连接服务，读取当前电脑会话并向电脑发送任务；手机显示电脑正在生成的文字、工具调用和子任务，可以查看并批准或拒绝电脑的待审批操作、停止任务以及切换电脑已打开的工作空间和当前连接的模型。操作均在电脑执行。完整功能需要电脑端 0.24.15 或更新版本。手机与电脑必须通过局域网或用户自行配置的 VPN 等网络互通；该项目不提供公网中继。可扫描电脑上显示的二维码填入 HTTPS 地址、SHA-256 指纹和配对令牌；扫码后仍需核对并点击保存，也可手动填写。扫码仅在本地处理相机画面，不会上传二维码。客户端固定证书并拒绝指纹不匹配的连接。电脑每次重新开启服务时需要重新配对。不要在不可信的地方公开配对令牌。

手机模型密钥和电脑配对令牌使用 Android Keystore 加密保存，应用数据不参与 Android 云备份。系统的文件提供程序决定哪些目录能授权；应用无法超出所选文件夹访问其他文件。

构建：安装 JDK 17 或 21、Android SDK Platform 35、Build Tools 和 Gradle 8.9，在本目录运行 `gradle :app:assembleDebug`。APK 位于 `app/build/outputs/apk/debug/`。发行构建需要配置自己的签名密钥。
