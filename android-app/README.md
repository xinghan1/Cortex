# Cortex Android

Android 8.0（API 26）及以上的原生客户端。手机模式将当前会话保存到设备，并通过用户配置的 OpenAI Chat Completions 兼容 HTTPS 接口调用模型。模型支持工具调用时，可使用系统文件夹选择器授权的目录列目录、读取和写入文本文件（单文件最多 1 MiB）。手机上的工具只访问授权目录；它不运行电脑端 shell 或官方 CLI。开始新会话会清除当前手机会话。

电脑模式连接桌面 Cortex 启用的手机连接服务，读取当前电脑会话并向电脑发送任务；手机显示电脑正在生成的文字和工具调用进度，可以查看并批准或拒绝电脑的待审批操作，也可停止电脑任务。操作均在电脑执行。手机与电脑必须通过局域网或用户自行配置的 VPN 等网络互通；该项目不提供公网中继。按电脑显示的 HTTPS 地址、配对令牌和 SHA-256 证书指纹配置，客户端固定该证书并拒绝指纹不匹配的连接。电脑每次重新开启服务时需要重新配对。不要在不可信的地方公开配对令牌。

手机模型密钥和电脑配对令牌使用 Android Keystore 加密保存，应用数据不参与 Android 云备份。系统的文件提供程序决定哪些目录能授权；应用无法超出所选文件夹访问其他文件。

构建：安装 JDK 17 或 21、Android SDK Platform 35、Build Tools 和 Gradle 8.9，在本目录运行 `gradle :app:assembleDebug`。APK 位于 `app/build/outputs/apk/debug/`。发行构建需要配置自己的签名密钥。
